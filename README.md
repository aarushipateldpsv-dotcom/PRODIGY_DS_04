# Task 04: Sentiment Analysis on Social Media Data

## 📌 Objective
Analyze and visualize sentiment patterns in social media data.

## 📂 Dataset
Sample dataset:  
https://github.com/Prodigy-InfoTech/data-science-datasets/tree/main/Task%204

## 🛠️ Tools & Libraries
- Python
- Pandas
- NLP (NLTK / TextBlob / Vader)
- Matplotlib / Seaborn

## 🔍 Steps Performed
1. Data cleaning:
   - Removed stopwords, punctuation
   - Lowercasing text
2. Text preprocessing:
   - Tokenization
   - Lemmatization
3. Sentiment analysis:
   - Positive / Negative / Neutral classification
4. Visualization:
   - Pie charts
   - Bar graphs
   - Word clouds

## 📊 Output
- Sentiment distribution
- Popular keywords
- Trend analysis

## 📌 Conclusion
Helps understand public opinion and user sentiment towards topics or brands.
